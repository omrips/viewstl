Model animation

The blue model spins. The red model moves and scales while rotating. Both use the legacy animation API, with independent playback controls.

Loading models…

viewer.animate_model(0, {
  delta: { rotationz: Math.PI * 2, msec: 5000, loop: true }
});
viewer.pause_model_animation(0);
viewer.resume_model_animation(0);

Motion starts when you press Play. Drag the view to orbit; scroll to zoom. Stop keeps the current pose. This example processes everything in your browser.
