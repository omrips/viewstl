# ViewSTL 2.0.0-rc.6

Adds center-preserving resizing, explicit file-unit correction, independent display units, model duplication, seven Z-up camera presets, named scene camera bookmarks, and on-demand surface area / validated volume measurements. Optional application controls are implemented in the plugin; the website remains static markup and styles plus its initializer.

VSB and VSJ retain size baselines, corrected units, display units, duplicate labels and bookmarks alongside existing animation state. Older scene manifests remain supported. Local models and measurements stay on the device. Legacy v1 files and releases remain unchanged.

New APIs: `get_model_size`, `resize_model`, `reset_model_size`, `set_file_units`, `duplicate_model`, `set_display_units`, `set_camera_view`, `get_camera_bookmarks`, `set_camera_bookmarks`, and `measure_model`. See the usage documentation for units and validation limits.
