# ViewSTL 2.0.0-rc.9

The plugin handles 3D models and scenes without requiring ViewSTL website markup.
`ViewerSession` adds a UI-independent loading queue, memory policy, scene placement,
center-preserving model editing and optional canvas manipulation. The existing
`StlViewer` rendering, analysis, saving and camera APIs remain available.

**App helper migration:** `mountViewstlApp` and `ViewstlApp*` types are removed from
the ESM/CommonJS/classic plugin distributions. They were a controller for the
ViewSTL website's specific HTML, not a general viewer API. Website controls,
dialogs and presentation now live in the website project, outside this repository
and npm packages. Consumers of that helper must migrate their own UI to
`ViewerSession`/`StlViewer`, or keep their existing pinned rc.8 distribution while
migrating. Earlier npm versions, GitHub releases and legacy v1 are retained.

The native JavaScript/WebGL2 renderer, lazy workers/CAD assets, local-file privacy,
VSB/VSJ serialization and separate `viewstl/node` API are preserved.

See [usage](../v2-usage.md) and the dated [verification record](../v2-verification.md)
for API details and tested scope.
