# ViewSTL 2.0.0-rc.8

Selection mode now opens the compact model-tool box immediately with Move
active. Click another model to select it, or drag it to select and move it in
one gesture. Rotate and Depth remain available in the same box. Turning Select
off, Done, Escape or a camera shortcut closes the box and restores viewing.
Narrowing the screen also exits desktop selection mode safely.

The plugin owns the tool behavior. Existing standalone model tools remain
available without desktop shortcuts. VSB binary download labeling and the
author/version banners introduced in rc.7 are retained.
