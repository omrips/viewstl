# ViewSTL v2.00 (2.0.0-rc.10)

- Binary STL imports recognize the legacy `STL File color` header alongside
  native ViewSTL, Materialise Magics and VisCAM/SolidView face colors.
- Pass `{ format: "stl", colors: true }` to `export_models()` or
  `download_models()` to save 5-bit RGB face colors using the legacy ViewSTL
  convention. The file still uses `.stl` and opens as ordinary geometry in
  readers that ignore the color extension.
- Standard binary STL remains the default. The existing VSB scene format
  and legacy releases are preserved.
