# ViewSTL 2.0.0-rc.7

Adds optional application shortcuts for Save, model selection mode, and seven
camera orientations. Hosts provide the buttons and responsive styling; the
plugin owns the handlers. Selection mode lets users click a model without
rotating the scene. Escape, camera shortcuts, model manipulation and hiding
the selection controls on resize restore normal viewing.

VSB downloads now use `application/octet-stream`, preventing the ZIP MIME label
from encouraging Android to append `.zip` to `.vsb`. Both modern and compatibility
VSB export APIs retain the established archive contents and scene compatibility.
Physical Android download behavior still requires a device retest.

The normal and minified plugin files now retain the previously requested
first-line author/version banner. Existing APIs, local-file privacy, native
WebGL 2 rendering and archived v1 distributions remain unchanged.
